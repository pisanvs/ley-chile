La Comisión de Peritos, fijó con fecha 20 de diciembre de 2007, en las cantidades de $337.500, para el lote Nº 44, $818.850, para el lote Nº 45, $473.850, para el lote Nº 46, $333.150, para el lote Nº 47, $116.100, para el lote Nº 48, $123.450, para el lote Nº 49, $99.600, para el lote Nº 50 y $123.750, para el lote Nº 51.
